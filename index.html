Sound mapping

Choose which attribute drives each musical dimension. Default keeps groups in different octaves and event types on different instruments.

Each actor gets a pitch in the chosen scale, with the Register attribute setting their octave. Each event plays the sender's note answered by the receiver's note as a harmonic interval. Instrument and Mode mappings let categorical or ordinal attributes (department, hierarchy, etc.) shape the sound.
