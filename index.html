musicalnetworks

Turn a relational event sequence into music.

1. Data

Mute groups by clicking on them.

2. Style and tempo

3. Sound mapping

Pick which attribute drives each musical dimension. Defaults reproduce the original mapping (groups → register, event types → instrument).

4. Listen

Each actor gets a pitch in the chosen scale, with the Register attribute setting their octave. Each event plays the sender's note answered by the receiver's note as a harmonic interval. Instrument and Mode mappings let categorical or ordinal attributes (department, hierarchy, etc.) shape the sound.

Source on GitHub. Built with Tone.js.
