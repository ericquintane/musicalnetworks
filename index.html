musicalnetworks

Turn a relational event sequence into music.

1. Data

CSV columns: time, sender, receiver (optional type, weight).

2. Style

3. Listen

Each actor gets a pitch in the chosen scale, with groups placed in different registers. Each event plays the sender's note answered by the receiver's note as a harmonic interval. Event types choose the instrument. Time of events drives onset; bursts become flurries, lulls become rests.

Source on GitHub. Built with Tone.js.
